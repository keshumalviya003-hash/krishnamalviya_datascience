# krishnamalviya_datascience# 🎬 Movie Dataset – Data Cleaning & Analysis

## 📌 Project Overview

This project focuses on cleaning and preparing a movie dataset for data analysis.

The dataset contains information about movies such as movie name, genre, release year, runtime, ratings, revenue, director, and other movie-related attributes.

The main purpose of this project is to identify and handle common data-quality issues before performing further analysis.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Load the movie dataset using Python and Pandas
- Understand the structure of the dataset
- Identify missing values
- Handle missing values appropriately
- Identify and remove duplicate records
- Rename columns for better readability
- Filter and analyze movies based on release year
- Prepare a clean dataset for further analysis
