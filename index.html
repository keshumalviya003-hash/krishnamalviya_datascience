🎬 Movie Dataset

Data Cleaning, Analysis & Visualization using Python, Pandas, Matplotlib and Seaborn.

📌 Project Overview

This project focuses on cleaning and analyzing a movie dataset. The goal is to prepare reliable data and perform basic exploratory analysis using Python.

🐍 Python

Used for data processing and analysis.

🐼 Pandas

Used for loading, cleaning and transforming the dataset.

📊 Matplotlib

Used to create data visualizations.

📈 Seaborn

Used for clear and attractive statistical charts.

🧹 Data Cleaning

The dataset was prepared before analysis by performing the following cleaning operations.

01

Missing Values

Missing values were identified and handled using suitable methods such as median values and "Unknown".

02

Duplicate Records

Duplicate rows were identified and removed from the dataset.

03

Column Names

Column names were standardized to make them easier to use in Python.

04

Filtering

Movies released before the year 2000 were filtered for analysis.

🎞️ Dataset Features

The project works with movie-related information including:

Feature Description
Movie Title Name of the movie
Genre Category or genre of the movie
Release Year Year in which the movie was released
Runtime Duration of the movie in minutes
IMDb Rating IMDb rating of the movie
Director Director of the movie

📊 Analysis Performed

The project includes the following analysis and visualizations:

🎭 Movies per Genre

A bar chart was created to show the number of movies belonging to each genre.

⭐ Average IMDb Rating

Average IMDb ratings were calculated and compared across different genres.

📅 Before 2000

Movies released before the year 2000 were filtered into a separate dataset for analysis.

🏆 Top Rated Movies

The project also identifies movies with the highest IMDb ratings.

✅ Conclusion

The movie dataset was cleaned by handling missing values, removing duplicate records and standardizing column names. The cleaned data was then used for filtering and visualization. The project provides a foundation for further exploratory data analysis and statistical analysis of movie data.
